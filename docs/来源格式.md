# 发布构建资料接口来源格式

支持 CMake File API codemodel v2，client-release/query.json 请求与 reply 下同名客户的 responses 对应。入口 /build/index 返回当前索引名称，/build/reply/NAME 读不可变回复；不能从 objects 列表绕过客户级 error。配置内 target.id 只在该配置及本次回复里定位，jsonFile 相对 reply 目录。target 的 paths 与 codemodel paths 区分 source/build 基准，isGenerated 不要求当前磁盘存在。源码组、编译组按下标关联，越界标 issue。changed 场景入口换索引，missing-target 缺目标文件。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://cmake.org/cmake/help/latest/manual/cmake-file-api.7.html。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
